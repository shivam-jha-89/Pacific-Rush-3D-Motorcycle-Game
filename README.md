A browser-playable motorcycle combat racer inspired by the road readability and outlaw energy of the 1991 classic, rebuilt as an original first-person Three.js experience.

Git clone - https://github.com/shivam-jha-89/Pacific-Rush-3D-Motorcycle-Game
 Live Demo - https://pacific-rush-3-d-motorcycle-game.vercel.app/

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. For a production build:

```bash
npm run build
npm run preview
```

## Controls

- `W` / `↑`: throttle
- `S` / `↓`: brake
- `A` / `D` or `←` / `→`: steer
- `Shift`: nitro
- `Space`: strike a nearby rival
- `P` / `Esc`: pause

Touch controls appear automatically on touch-first devices.

## Included

- True rider-eye view with handlebars, tank, windscreen, mirrors, controls, and smooth suspension response
- Procedural 3D coastal-city course with continuously recycled curves, wet asphalt, detailed traffic, fog, sunset lighting, layered building facades, palms, and roadside infrastructure
- Six AI rivals with lane changes, attacks, catch-up behavior, health, wobble, and takedown states
- Traffic collisions, rider health, nitro, speed/gear telemetry, checkpoints, race position, and results
- Synthesized Web Audio engine, boost, strike, countdown, and impact sounds
- Desktop and mobile-responsive HUD with keyboard and touch input

All meshes, materials, textures, audio, and game logic are created at runtime; no proprietary game assets are included.
